# project-gestion-salle-de-sport
Application de bureau Python (Tkinter, SQLite) pour la gestion d'une salle de sport. Elle assure le suivi des adhérents, abonnements (statuts automatisés) et paiements. Son tableau de bord regroupe statistiques, alertes et graphiques. Projet réalisé à 3 (sur GitHub) avec une architecture séparant BDD, logique métier et interface.
